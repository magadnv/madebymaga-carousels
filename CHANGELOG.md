# Changelog

## 0.1.0 (2026-11-17)

First release.

- `createCarousel()` with three layouts: Drift, Orbit, Fan
- `setLayout()` morphs between layouts, optionally with new items
- Drag, wheel, keyboard, hold state, autoplay, credits on tap
- Events: `change`, `layoutchange`, `select`
- Custom layouts on the shared pose grid (`P0`)
- Reduced motion, live region, `destroy()` leaves no trace
- Types in `types/index.d.ts`, tests with Vitest
